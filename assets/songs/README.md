# 歌曲：放檔、切段、接進遊戲

歌由作者在 Suno 製作。原檔不進 git（`.gitignore` 擋 `assets/songs/*.mp3` 與 `assets/songs/cuts/`），放進這個資料夾以後，兩個指令切段、接進遊戲。

## 放好之後跑

    python3 src/songs_times.py            # 由 docs/music/*.lrc 轉出逐句時間 → assets/songs/times.json（換了歌檔才需要重跑）
    python3 src/songs_cut.py --build      # 切段 → assets/songs/cuts/，再 build

只重切某幾段：`python3 src/songs_cut.py --only ember_b1,night_sc --build`。每一段開頭是 `OK` 或 `FAIL`；`FAIL` 的段落不會被接進遊戲。

## 句子時間從哪來

- **六首真歌都用手動句時間**（不再用語音辨識對齊）：`〈餘燼〉` 三版與 `〈晚安，台南〉` 用公開站做的 LRC（`site/make_lrc.py`，openai-whisper 字詞時間 + 單調對齊 + 抽查），轉成 `times.json`；`〈港邊的燈〉` 台語辨識聽不出字，前 8 句由人看能量低谷手標（`src/songs_cut.py` 的 `MANUAL_LINES`）。
- **只在音檔指紋（md5 前 10 碼）對得上時啟用**：換了歌檔而時間沒重做，工具會退回辨識對齊，不會把舊時間套到新歌上；測試替身（`_fixture/`）也因此不受影響。
- 手動時間只有句首可靠，句尾是估的。切點找法：句首往前（最多 lead 秒）找人聲前的安靜處；句尾在下一句開唱前往回找最靜處；**後面接長間奏**（例如副歌最後一句到第三段中間有 25 秒）時，用辨識取該句最後一個字的時間，在那之後找最靜處（`vocal_end`）。Suno 常把句尾多唱一遍（〈晚安，台南〉副歌「我聽見就回家，就回家」），也會一起算進去。
- 切點深度（切點比前後各 1 秒內最響處低多少 dB）≥4 dB 才算 OK。前奏中段這種沒縫的切點（`rel`）改用 0.3 秒淡入，不做這項檢查。
- 手動時間的歌略過「切好後頭尾辨識比對」驗證（辨識本身就聽不準台語，其他歌的辨識也不如 LRC 可靠）；仍做切點深度與收音機頻譜檢查。

## 實際接線時的限制（先知道）

- **歌詞自動前進只能用固定間隔。** Larch 的 `autoAdvance` 只有卡片層一個 `delayMs`，逐句沒有各自的間隔。工具把歌詞分組（一張畫面 1 到 3 句），挑一個 delay 讓換頁貼近每句開唱的時間；建置時印出預測誤差。
- 歌卡設成「無法打斷」（玩家點了不會跳頁），不然歌詞會跑在歌前面。想允許跳過：`src/songs.py` 的 `UNINTERRUPTIBLE = False`。
- 歌卡是把原本那張卡切成三張：前（原代號）、歌（`代號__song`）、後（`代號__post`）。**唱詞必須連續**（中間不能夾旁白），夾了旁白的話，旁白會落到歌後面的卡。結局 A 第一段（`ending_a1`）因此把原本插在唱句之間的畫面移到唱完之後。
- **地圖調查點觸發的卡（`m_radio_on`、`mem0_market`）換不了曲（實測），所以收音機歌是疊在地圖背景曲上的**，用逐句 `sfxUrl`；sfx 只在當句播，玩家翻頁就停，所以前奏、第一句、第二句各自一段。實際響度：地圖背景曲約 -16.2 LUFS 掛 `bgmVolume` 0.4 = 約 -24.2；收音機 -17 LUFS 掛 `sfxVolume` 0.9 = 約 -17.9，高出約 6 dB。
- 〈港邊的燈〉在 `m_radio_on` 只有第一句掛得上（一句一檔），之後的對話（九八點七、哼歌、你唱錯了）沒有聲音，是引擎只認「當句播」的限制。
- 〈餘燼〉合聲版（`餘燼-合聲.mp3`）遊戲裡不用，只在公開站原聲帶頁播放。

## 驗證做了什麼

`tests/songs_check.py`（接線結構）、`tests/songs_sfx.mjs`（收音機的歌檔真的在對應那一句播）、`tests/songs_sync.mjs`（歌卡的歌詞出現時間對照開唱時間，真實時間）、`tests/play_full.mjs`（A/B/C 全劇，`AUDIO=1` 印出實際換曲順序與歌檔）。

## 測試用的替身

`_fixture/` 是用語音合成念歌詞做的替身，只用來測流程，不是正式歌檔，不進 git。`SONGS_DIR=assets/songs/_fixture python3 src/songs_cut.py` 才會處理它；預設只讀 `assets/songs/`。替身檔沒有指紋對得上的手動時間，所以走辨識對齊。
