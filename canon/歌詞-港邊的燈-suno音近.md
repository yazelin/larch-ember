# 〈港邊的燈〉給 Suno 的音近字版（試）

畫面上的歌詞與劇本一律用正字（「轉來」，教育部辭典寫 tńg--lâi）。
Suno 唱台語會用華語讀音唸漢字，「轉」會唱成 zhuǎn，所以貼進 Suno 的 Lyrics 時，把唸錯的字換成華語裡音近的字。
作者 2026-10-21 指出：「轉」要換成「瞪」。下面只換這一個字，其他字先照原樣，聽過再決定要不要換。

## 貼進 Suno 的 Lyrics

```
[Verse]
港邊的燈 一葩一葩光
討海的人 猶未瞪來
阮徛佇岸邊 等你的船
風吹冷冷 心肝燒燒

[Chorus]
燈若熄 船就到
阮的心 替你留一葩
燈若熄 船就到
阮佇遮 等你瞪來
```

## 聽的時候看這幾個字（我猜它們也可能被唱成華語，沒有驗證過）

| 字 | 正確台語 | 可能被唱成 |
|---|---|---|
| 猶未 | iáu-bē | yóu wèi |
| 阮 | gún | ruǎn |
| 徛 | khiā | 不確定 |
| 佇遮 | tī-tsia | zhù zhē |
| 一葩 | tsi̍t-pha | yī pā |

哪個字唱錯了，把字和秒數告訴我，我替它找音近字再換。
遊戲裡只用一小段，必要時只留伴奏。
