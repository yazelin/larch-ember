# 《最終遺忘的橘色餘燼》劇本（第三稿）

格式：每個 `##` 是一張卡或一段地圖台詞，標題是程式取用的代號。每一行「講者：台詞」。
- 「余靜：」是她說出口的話；「余靜（心）：」是她心裡的話，只寫具體的念頭，不寫總結的感想。
- 「旁白：」只交代畫面上看得到的事，不解釋人的心情。
- 標 `〔掉字〕` 的句子，會隨落日逐漸變成「……」，程式依時間替換。
- 台語台詞寫台語漢字，括號裡附華語意思給字幕。

設計依據：`design/重寫.md` 第四稿（2026-10-19 定稿）。第一稿的審稿意見在 `design/審稿-2.md`，場景來源對照在文末。

## 仍不夠好的地方

- 票根句同時負責交代河岸演出和兩人初識前的單向記憶，若作者指定另一首現實中唱過的歌，需全稿統一替換。
- 結局 C 保留了搜救與找到她的畫面，但沒有交代明確死因；目前讓讀者從漲潮、濕裙襬和一週後的追思場推知結果，情緒可能仍偏含蓄。
- m_letter 的實用提醒已壓在八行內，聲音是否像四十三歲的余靜，仍可由作者按真實口吻微調。
